# 摸鱼助手 (FishPeek) 🐟

超低内存占用、无窗口黑框干扰的 Windows 摸鱼隐形窥视工具。

---

## 🌟 核心特性

1. **智能选择目标窗口**：
   - **支持任务栏多窗口缩略图精准选择**：当 Chrome、Edge、微信等应用打开了多个窗口时，鼠标悬停在任务栏图标上展开多个缩略图卡片（如“百度一下”、“Google Gemini”），**直接点击其中某一个卡片，即可精准绑定该特定窗口**！
   - **交互式点击选择**：在控制面板或托盘菜单中点击【🎯 选择鼠标下窗口】，直接点击屏幕任意应用窗口即可绑定，自动排除摸鱼助手自身。
   - **快捷键即按即选**：随时把鼠标悬停在目标窗口上按下快捷键（默认 <kbd>Ctrl</kbd> + <kbd>F8</kbd>）直接选定。
2. **移入显形 / 移出隐形（Hover Peek 模式）**：
   - 目标隐藏时，鼠标移入该窗口原本所在区域，达到指定悬停延迟时间（支持自定义毫秒，也可勾选**取消延迟（0ms 划入即显）**），窗口自动显现。
   - 鼠标移出该窗口范围，窗口立即自动隐藏（`ShowWindow(SW_HIDE)`），任务栏无任何图标痕迹。
3. **🔇 隐形时自动静音该应用 / 显现时恢复声音**：
   - 基于 Windows 原生 Core Audio API 实现进程级独立声音控制。
   - 窗口隐藏时，自动静音该应用，防止视频/音频在后台发声暴露；窗口显示时，自动恢复该应用声音。
   - 可以在控制面板中自由选择是否开启该功能。
4. **🛑 快捷键一键关闭所选窗口并退出本程序（Boss Kill）**：
   - 支持设置独立快捷键（默认 **<kbd>Ctrl</kbd> + <kbd>F11</kbd>**），一键彻底关闭该窗口对应应用（优先优雅退出，防卡死强杀），**同时彻底退出 FishPeek 自身**，现场不留任何痕迹。
   - 可以在控制面板中随时开启或关闭此功能，避免误触。
5. **全局老板键（Boss Key）与解除选择热键**：支持一键强制显隐切换（<kbd>Ctrl</kbd> + <kbd>F9</kbd>）与一键安全解除选择（<kbd>Ctrl</kbd> + <kbd>F10</kbd>）。
6. **可视化控制面板（Control Panel）**：
   - 托盘右键选择 **“⚙️ 打开控制面板...”** 或直接**双击托盘图标**呼出。
   - **键盘直录快捷键**：点击输入框后直接在键盘上按下组合键（如 `Ctrl+Alt+A`、`Alt+Q`、`Ctrl+F8`），即按即录！
   - 设置自动持久化保存到 `config.json`。
7. **安全保护机制**：
   - 自动过滤桌面和系统保留组件，防止误选。
   - 解除选择、修改目标或退出程序时，会自动安全还原窗口显示和声音，绝不丢失窗口与声音。

## ⌨️ 默认快捷键一览（均可在控制面板中直接按键录制修改）

| 功能 | 默认快捷键 | 说明 |
| :--- | :--- | :--- |
| **选择目标窗口** | <kbd>Ctrl</kbd> + <kbd>F8</kbd> | 将鼠标停留在想摸鱼的窗口上按下，托盘将提示选择成功 |
| **老板键显隐切换** | <kbd>Ctrl</kbd> + <kbd>F9</kbd> | 无论鼠标在何处，立即强制切换当前目标窗口的显/隐（连带自动静音/恢复） |
| **解除选择窗口** | <kbd>Ctrl</kbd> + <kbd>F10</kbd> | 立即解除选择并安全恢复窗口正常显示和声音 |
| **关闭所选窗口并退出** | <kbd>Ctrl</kbd> + <kbd>F11</kbd> | 一键关闭所选应用并彻底退出 FishPeek 助手（可在控制面板中开关） |

## 🎛️ 控制面板使用指南

1. **选择多窗口应用（如 Chrome 多窗口、多个文档等）**：
   - 点击面板中的 **【🎯 选择鼠标下窗口】** 按钮进入等待状态；
   - 鼠标移至任务栏 Chrome 图标上，等待系统展开多个缩略图卡片预览；
   - **点击您想要绑定的那一个缩略图卡片**，程序会自动捕获被唤醒的特定窗口并完成绑定！
   - 如需中途取消，按键盘 <kbd>Esc</kbd> 键或鼠标右键退出。
2. **隐藏自动静音开关**：
   - 勾选 **“🔇 隐藏时自动静音该应用，显示时恢复声音”**：目标窗口隐藏即刻静音，移入显现即刻发声。
3. **关闭窗口并退出快捷键开关**：
   - 勾选 **“🛑 启用快捷键一键关闭所选窗口并退出本程序”**：允许使用快捷键关闭应用并退出；取消勾选则禁用此快捷键防止日常误触。
4. **键盘直接输入快捷键**：
   - 点击任意快捷键输入框，直接在物理键盘上同时按下您的组合键（如 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Q</kbd> 等），松开即录入完成。
5. **保存与收起**：
   - 点击 **“💾 保存并应用设置”** 即刻生效并持久化到本地。
   - 点击右上角 `[X]` 或“隐藏到托盘”将安静收回托盘后台。
